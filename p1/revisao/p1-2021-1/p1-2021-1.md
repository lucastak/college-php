## Questão 1 - 1,0 ponto

Exemplo:

```php
// Exemplo de entrada (array de strings)
$entrada = [ 'maçã', 'uva', 'maçã', 'banana', 'goiaba', 'uva', 'maçã', 'banana' ];
$saida = contabilizar( $entrada );
var_dump( $saida );

// array(4) { ["maçã"]=>int(3), ["uva"]=>int(2), ["banana"]=>int(2), ["goiaba"]=>int(1) }
```

## Questão 3 - 8,0 pontos

Considere o banco de dados MySQL listado a seguir, de nome `2021-1-p1`, no *host* `127.0.0.1`, com *charset* `utf8`, *collate* `utf8_unicode_ci`, usuário `root` e senha vazia.

```sql
CREATE DATABASE `2021-1-p1` DEFAULT CHARACTER SET utf8 COLLATE utf8_unicode_ci;
USE `2021-1-p1`;

CREATE TABLE `vacina` (
  `id` int(11) NOT NULL AUTO_INCREMENT,
  `nome` varchar(30) COLLATE utf8_unicode_ci NOT NULL,
  `fabricante` varchar(60) COLLATE utf8_unicode_ci NOT NULL,
  `doses` int(11) DEFAULT '0',
  `eficacia` decimal(10,2) DEFAULT '0.00',
  `eficacia_delta` decimal(10,2) DEFAULT '0.00',
  `perda_mensal` decimal(10,2) DEFAULT '0.00',
  PRIMARY KEY (`id`),
  UNIQUE KEY `nome` (`nome`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8 COLLATE=utf8_unicode_ci;

INSERT INTO vacina ( nome, fabricante, doses, eficacia, eficacia_delta, perda_mensal ) VALUES
( 'CoviKiller', 'Acme S/A', 2, 0.95, 0.65, 0.05 ),
( 'CoviX', 'FarmaCo', 2, 0.75, 0.45, 0.08 ),
( 'CoviUltra', 'UltraDrugs', 1, 0.65, 0.50, 0.10 ),
( 'Farewell 19', 'Health 1', 2, 0.85, 0.60, 0.06 );
```

> **Nota:** os dados cadastrados na tabela `vacina` são fictícios.

A tabela `vacina` representa vacinas contra Covid-19. O campo `nome` denota o nome da vacina, como `CoviKiller`. O campo `fabricante` denota o fabricante da vacina, como `Acme S/A`. O campo `doses` representa quantas doses devem ser aplicadas.

Os campos `eficacia` e `eficacia_delta` denotam a eficácia média da vacina, em valores percentuais - por exemplo, `0.95` equivale a `95%` -, após a aplicação do número de doses indicado no campo `doses`. O campo `eficacia` desconsidera a variante Delta da efetividade e o campo `eficacia_delta` a considera. Sabe-se que, para a variante Delta, a eficácia das vacinas é geralmente menor.

O campo `perda_mensal` denota a perda mensal de eficácia da vacina, segundo informações do fabricante, em valores percentuais - por exemplo, `0.05` equivale a `5%`.

### a) Classe `Vacina` - 1,0 ponto

Considere a existência do arquivo `vacina.php` com a classe `Vacina`, declarada em um *namespace* `vac`, com conteúdo parcial listado abaixo. A classe possui atributos privados em *camelCase* correspondentes aos campos existentes na tabela `vacina`. Por exemplo, o atributo `perdaMensal` corresponde ao campo `perda_mensal` da tabela. A classe também possui *getters*, *setters* e um construtor.

```php
namespace vac;

class Vacina {
    private $id;
    private $nome;
    private $fabricante;
    private $doses;
    private $eficacia;
    private $eficaciaDelta;
    private $perdaMensal;

    public function __construct(
        $id = 0,
        $nome = '',
        $fabricante = '',
        $doses = 0,
        $eficacia = 0,
        $eficaciaDelta = 0,
        $perdaMensal = 0
    ) {
        $this->setId( $id );
        $this->setNome( $nome );
        $this->setFabricante( $fabricante );
        $this->setDoses( $doses );
        $this->setEficacia( $eficacia );
        $this->setEficaciaDelta( $eficaciaDelta );
        $this->setPerdaMensal( $perdaMensal );
    }

    /* Getters e Setters omitidos por questões de espaço */
}
```

Adicione à classe um método público `eficaciaAposMeses`, que calcule o valor da eficácia da vacina após um certo número de meses - primeiro argumento, número inteiro - e uma indicação opcional se deve ou não considerar a variante Delta - segundo argumento, valor booleano, com *default* `false`.

Por exemplo, considere uma vacina com eficácia `0.95`, eficácia com Delta de `0.65` e perda mensal de `0.05`:

- Com `1` para o número de meses e sem considerar a Delta (`false`), deve ser retornado `0.95 - (1 * 0.05) = 0.90`.
- Considerando a Delta (`true`), deve ser retornado `0.65 - (1 * 0.05) = 0.6`.

Faça com que o método considere um número negativo de meses como zero (`0`) e nunca retorne um valor inferior a zero.

### d) Aplicação de linha de comando - 2,4 pontos

A aplicação deve ficar executando em *loop* até que a opção `0` seja escolhida. Deve-se fazer tratamento de exceções sempre que um método invocado puder lançá-la e verificar os valores de entrada antes de processá-los.

Ao escolher a opção `2`, deve ser solicitado ao usuário o `id` da vacina. Se a vacina existir no repositório - instância correspondente a `RepositorioVacina` -, após consulta pelo seu `id`, deve-se solicitar que o usuário digite um número de meses e informe se deseja considerar a variante Delta: `S` para sim e qualquer outra coisa para não. Então, utilize a instância encontrada para calcular e imprimir a eficácia segundo os parâmetros informados.
