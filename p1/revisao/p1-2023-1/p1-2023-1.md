## Questão 1 - 2,0 pontos

Considere o exemplo de arquivo texto `pereciveis.csv` abaixo, que poderia guardar dados de diversos produtos perecíveis, no formato CSV - formato de valores separados por vírgula ou ponto e vírgula -, cuja data de validade pode estar ultrapassada.

Considere que o dia atual é `05/05/2023`.

```csv
Descrição;Validade
Iogurte desnatado 1L;06/05/2023
Cerveja Acme 600ml;04/05/2023
Leite Integral Mimosa 1L;05/05/2023
Queijo Minerim 250g;03/05/2023
```

Faça um *script* que leia o arquivo CSV, que pode ter produtos diversos dos que estão no exemplo acima, e então imprima quais produtos estão fora do prazo de validade - vencidos - e há quantos dias.

## Questão 2 - 2,5 pontos

Considere o banco de dados `mma`, localizado em `localhost`, com *charset* `utf8`, usuário `dev`, senha `123456` e que tenha a tabela `lutador`, cuja estrutura é indicada abaixo:

```sql
CREATE TABLE lutador (
    id INT NOT NULL AUTO_INCREMENT PRIMARY KEY,
    nome VARCHAR(100) NOT NULL,
    peso_em_quilos DECIMAL(5,2) NOT NULL,
    altura_em_metros DECIMAL(3,2) NOT NULL
) ENGINE=INNODB;
```

### a) 2,0 pontos

Faça um *script* que consulte e liste cada lutador, com todos os seus dados.

### b) 0,5 ponto

Após a listagem realizada no *script* anterior, imprima os seguintes dados, consultados do banco de dados:

- número total de lutadores;
- média de alturas;
- maior altura;
- maior peso.

## Questão 3 - 4,5 pontos

Considere o arquivo `lutador.php` abaixo, que contém a classe `Lutador`:

```php
class Lutador {
    public $id = 0;
    public $nome = '';
    public $pesoEmQuilos = 0.00;
    public $alturaEmMetros = 0.00;

    public function __construct(
        $id = 0,
        $nome = '',
        $pesoEmQuilos = 0.00,
        $alturaEmMetros = 0.00
    ) {
        $this->id = $id;
        $this->nome = $nome;
        $this->pesoEmQuilos = $pesoEmQuilos;
        $this->alturaEmMetros = $alturaEmMetros;
    }
}
```

### a) 0,5 ponto

Crie um arquivo `repositorio-lutador.php` com um *namespace* `Mma` que contenha uma interface que represente um repositório de lutadores - abstração responsável por recuperar e manipular lutadores em algum meio de persistência, como um arquivo ou um banco de dados - e que contenha métodos para:

1. adicionar um lutador - objeto da classe `Lutador` - no meio de persistência;
2. remover um lutador, a partir de um `id` fornecido, do meio de persistência.

### b) 2,5 pontos

Crie um arquivo `repositorio-lutador-em-bdr.php`, com um *namespace* `Mma`, que implemente a interface anteriormente indicada para o banco de dados relacional - BDR - indicado na questão anterior.

Na implementação, não utilize quaisquer funções de impressão, como `echo` ou `die`.

### c) 1,5 ponto

Crie um arquivo de *script* `remover.php` que **não** esteja no *namespace* `Mma` e que:

1. solicite que o usuário informe o `id` de dois lutadores;
2. utilizando controle de transação e o repositório criado anteriormente, remova os lutadores informados.

## Questão 4 - 1,0 ponto

Faça uma função para formatar um número de telefone - *string* - recebido como argumento que, somente se o número contiver 10 ou 11 caracteres e esses forem numéricos, retorne o telefone formatado. Do contrário, deve retornar uma *string* vazia.

O formato do telefone para quando ele tiver 10 caracteres, como `2225271727`, é:

```text
(22) 2527-1727
```

O formato para quando tiver 11 caracteres, como `22988776655`, é:

```text
(22) 98877-6655
```
