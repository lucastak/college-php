## Questão 1 - 2,5 pontos

Crie um arquivo `produtos.php` com a função:

```php
inventario( array $produtos ): array
```

A função deve receber um *array* associativo em que as chaves são *strings* que representam produtos e os valores são *arrays* que contêm dados sobre a quantidade e o preço do produto.

A função deve calcular o valor total de cada produto e retornar um novo *array* associativo em que as chaves são os nomes dos produtos e os valores são os respectivos valores totais.

### Exemplo de entrada

```php
[
    "maçã"   => [ "quantidade" => 10, "preço" => 10.00 ],
    "banana" => [ "quantidade" => 5,  "preço" => 6.00 ]
]
```

### Saída

```php
[
    "maçã"   => 100.00,
    "banana" => 30.00
]
```

> **Observação:** assuma que o *array* de entrada sempre terá a estrutura correta e que os valores numéricos serão válidos.

```php
<?php // Carro.php
class Carro {
    public $id = 0, $nome = '', $fabricante = '', $preco = 0.00;

        $fabricante = '',
        $preco = 0.00
    ) {
        /* Considerar a atribuição dos argumentos para os atributos da classe */
    }

```

Considere o arquivo `RepositorioCarro.php`, com uma interface para persistência de carros com os métodos a seguir, observando atentamente todos os seus comentários:

```php
<?php // RepositorioCarro.php
require_once 'Carro.php';

/** Repositório de Carros. Apenas lança RepositorioException em seus métodos. */
interface RepositorioCarro {
    /** Adiciona um carro, que deve receber o id gerado pelo banco de dados */
    function adicionar( Carro &$carro );

    /** Atualiza os dados de um carro, exceto seu id, que é utilizado para localizá-lo */
    function atualizar( Carro $carro );

    /**
     * Atualiza os preços de todos os carros em um percentual positivo ou negativo.
     * Exemplo: -10.00 (%). Deve utilizar controle de transação.
     */
    function atualizarPrecosEmPercentual( $percentual );

    /** Remove um carro pelo id informado, retornando true se removeu ou false se não. */
    function removerPeloId( $id );

    /** Retorna todos os carros, como objetos da classe Carro */
    function todos();
}
?>
```

Considere o arquivo `RepositorioException.php` abaixo, pertencente ao *namespace* `excecoes`:

```php
<?php // RepositorioException.php
namespace excecoes;

class RepositorioException extends \RuntimeException {}
?>
```

### a) Repositório em banco de dados - 5,5 pontos

Crie a classe `RepositorioCarroEmBDR`, em um arquivo PHP homônimo, para que implemente a interface descrita anteriormente para tratar da persistência de carros no banco de dados relacional descrito abaixo.

Utilize PDO para interagir com o banco de dados e somente lance a exceção `RepositorioException` em seus métodos. A classe não deve instanciar PDO, direta ou indiretamente.

Para sua implementação, considere o banco de dados MySQL de nome `p1`, localizado no endereço IP `192.168.0.10`, com caracteres no formato `utf8`, usuário `gerente` e senha `g3X$t0R`, com a estrutura a seguir:

```sql
CREATE TABLE carro (
    id INT NOT NULL AUTO_INCREMENT PRIMARY KEY,
    nome VARCHAR(100) NOT NULL UNIQUE,
    fabricante VARCHAR(60) DEFAULT '',
    preco DECIMAL(10, 2) DEFAULT 0,
) ENGINE=INNODB;
```

### b) Cadastro - 2,0 pontos

Crie um arquivo `cadastro.php` que solicite ao usuário os dados de um carro - exceto seu `id` -, valide seus dados e utilize o repositório criado anteriormente para salvá-lo, tratando exceções adequadamente.

Caso o carro seja salvo com sucesso, mostre uma mensagem que indique isso e exiba seu `id`.

Considere as seguintes regras de validação:

- o nome deve ter entre 2 e 100 caracteres;
- o fabricante deve ter no máximo 60 caracteres e não pode conter números;
- o preço deve ser um número e ser igual ou superior a cinco mil.
